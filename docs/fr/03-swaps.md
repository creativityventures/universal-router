# Universal Router — swaps

Les modules de swaps connectent les chemins V2/V3/V4 et transportent les montants intermédiaires. Les chained actions permettent de réutiliser une sortie précédente comme entrée suivante, tandis que les limites de montant protègent l’utilisateur contre un résultat inattendu.
